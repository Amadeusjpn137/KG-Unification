# KG-Unification: SymPy Verification Codes

This repository contains the SymPy verification codes for the paper *"Unifying Spin, Statistics, and Cosmology: Emergent Gravity from a Multi-Component Klein-Gordon Framework"* (QEDxQED, 2025). The codes perform symbolic and numerical verifications for key calculations, including the Feshbach-Villars (FV) Hamiltonian, Darwin term, vacuum energy density (\(\rho_{\mathrm{vac}}\)), emergence index (\(\epsilon\)), and other physical quantities.

## Files
- `sympy_verifications.py`: Main script for symbolic and numerical calculations.

## Dependencies
- Python 3.6+
- SymPy (`pip install sympy`)
